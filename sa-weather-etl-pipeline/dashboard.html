How it works

Pipeline architecture

Four stages, orchestrated by Apache Airflow every 6 hours, running in Docker.

📡

Extract

Pulls raw weather JSON from OpenWeatherMap for a city in every province.

🔧

🔍

→
💾

Load

Writes simultaneously to CSV and PostgreSQL — the dual sink this dashboard reads from.
